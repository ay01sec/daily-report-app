作業日報アプリ -CDS- ヘルプ

操作マニュアル

ログイン

1. 企業コード（8桁の数字）を入力します
2. メールアドレスとパスワードを入力します
3. 「ログイン」ボタンをタップします

企業コードは前回入力した値が自動的に保存されます。パスワードを忘れた場合は「パスワードを忘れた方」をタップしてください。

ホーム画面

ログイン後のメインページです。自分が作成した日報の一覧が表示されます。

  • 月切替: 画面上部のドロップダウンで表示する月を変更できます
  • 日報一覧: 日付・現場名・ステータスがカード形式で表示されます
  • 新規作成: 「+ 新規作成」ボタンから新しい日報を作成できます
  • 更新: 画面を下に引っ張ると最新データに更新されます

ステータスの見方

色 ステータス 意味
グレー 下書き 保存済み。署名・提出がまだ
黄色 署名済み 署名を取得済み。まだ提出していない
青 提出済み 管理者に送信済み。承認待ち
緑 承認済み 管理者に承認された
赤 却下 差し戻し。修正が必要

日報を作成する

手順1: 日報の入力

1. ホーム画面の「+ 新規作成」ボタンをタップします

2. 以下の項目を入力します：

  • 作業日（必須）: 日付を選択します
  • 天候: 晴れ・曇り・雨・雪から選択
  • 現場名（必須）: 稼働中の現場から選択
  • 作業員（必須）: 1名以上の作業員情報を入力
  • 連絡事項: 管理者への連絡事項を記入
  • 写真: 現場の写真を最大3枚まで添付可能

手順2: 保存

  • 「下書き保存」: 下書きとして保存します。後から編集できます
  • 「元請サインへ進む」: 保存してから得意先の署名画面に進みます

得意先の署名を取得する

1. 「元請サインへ進む」をタップすると署名画面が表示されます
2. スマートフォンを得意先の担当者にお渡しください
3. 担当者に画面上に指で署名してもらいます
4. 書き直す場合は「クリア」ボタンで消去できます
5. 署名が完了したら「サイン完了」ボタンをタップします

日報を提出する

1. ホーム画面から「署名済み」の日報をタップします
2. 編集画面で内容を確認します
3. 「送信する」ボタンをタップします
4. 確認ダイアログで「送信する」を選択します
5. 提出が完了するとホーム画面に戻ります

提出後は内容の変更ができなくなります。提出前に内容をよく確認してください。

PDF・QRコードを確認する

承認済みの日報にはPDFとQRコードが生成されます。

1. ホーム画面から「承認済み」の日報をタップします
2. 詳細画面の下部に「PDF・QRコード」セクションが表示されます
3. 「PDF表示」をタップすると日報のPDFを表示します
4. 「QRコード」をタップするとPDFへのQRコードを表示します

オフラインでの利用

インターネットに接続できない環境でも、下書きの保存ができます。

  • オフライン時: 画面上部に「オフラインモード」と表示されます
  • 下書き保存: 日報の入力内容は自動的にスマートフォンに保存されます
  • 自動同期: インターネットに接続されると、保存した下書きが自動的にサーバーに送信されます
注意: 署名と提出にはインターネット接続が必要です。

よくある質問

パスワードを忘れた場合は？

ログイン画面の「パスワードを忘れた方」からリセットメールを送信してください。

企業コードがわからない場合は？

管理者にお問い合わせください。

現場が選択肢に表示されない場合は？

管理者が現場を登録していない可能性があります。現場のステータスが「進行中」になっているか管理者に確認してください。

日報を提出した後に修正したい場合は？

提出済みの日報は修正できません。管理者に連絡して却下してもらい、却下後に修正・再提出してください。
